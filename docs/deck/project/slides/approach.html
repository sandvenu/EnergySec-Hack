Trusted rApp Framework · 04

Every action an agent takes is a tool call through one gateway at the SMO boundary, the same shape as Amazon Bedrock AgentCore Gateway. Three stages: request checks (identity, kill switch, screening of what the agent says, the change budget and the risk tier), a Cedar policy over the tool call, and screening of untrusted text on the way back, so a poisoned alarm is quarantined before the model ever reads it. The twin accepts commands only from the gateway, so no agent can go around it. Low-risk actions run; high-risk ones are replayed on the twin first and wait for a human. And every outcome is written to a signed ledger. If any dependency is down, the action is denied: it fails closed.
