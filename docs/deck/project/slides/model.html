The model is not the control. The boundary is.

Strands vendor agent on Claude Opus 5.5 · TelcoAgentBench and D1–D5 rehearsals, Oct 22 2026 · 03

This is the finding that shaped the design. Claude refused the crude attacks, the “ignore previous instructions” kind, even with all our defenses off, and it reported them. But a plausible forged maintenance ticket, approved-looking, with no trigger words, made it switch off the busiest critical cell in two of three rehearsal runs. Its behaviour varies run to run. With the framework on, nothing harmful ran in any run. So the security claim cannot rest on the model’s judgement; it has to be enforced outside the model.
