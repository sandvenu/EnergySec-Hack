The barrier

Operators want AI agents to run the network. Nothing yet guarantees what an agent will do.

Third-party rApps

O-RAN opens the SMO to rApps from any vendor. Their code, models and prompts are not the operator’s.

Agents read untrusted text

Alarms, tickets and KPI notes feed the model. One forged ticket can steer an agent into a harmful change.

Safeguards are manual

Protected-site lists, change caps and change boards live on paper and in people, not at the interface the agent calls.

Trusted rApp Framework · 02

The barrier is trust, not capability. O-RAN deliberately opens the SMO to rApps from many vendors, and operators are moving to agentic operations. But an agent that reads alarm text and tickets can be steered by them, and today’s safeguards (exclusion lists for hub sites, caps on how many cells change per window, change boards) are manual. Nothing enforces them at the point where an agent acts, and nothing proves afterwards what was allowed and why.
